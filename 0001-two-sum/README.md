# 1. Two Sum

🔗 Problem Link: https://leetcode.com/problems/two-sum/

## 🧠 Approach
Use nested loops to check every pair of elements and return the indices whose sum equals the target.

## ⏱ Complexity
- Time Complexity: O(n²)
- Space Complexity: O(1)

## 📥 Example
Input: nums = [2,7,11,15], target = 9  
Output: [0,1]
