# 27. Remove Element

🔗 Problem Link: https://leetcode.com/problems/remove-element/

## 🧠 Approach
Traverse the array and copy all elements that are not equal to `val` to the front of the array using a pointer `k`.

## ⏱ Complexity
- Time Complexity: O(n)
- Space Complexity: O(1)

## 📥 Example
Input: nums = [3,2,2,3], val = 3  
Output: 2
